# Kubernetes Lab (Ansible)

Automated Kubernetes cluster deployment using Ansible.

## Stack
- Kubernetes (kubeadm)
- Calico (networking)
- MetalLB (load balancer)
- Private Docker Registry
- Ansible

## Features
- Cluster bootstrap (control-plane + workers)
- Network configuration (Calico VXLAN)
- LoadBalancer support (MetalLB)
- Private image registry integration
- Idempotent Ansible roles
